# StreamHub-HlsEncoded 🎬

A tiny Netflix-like streaming app built with FFmpeg.

## Features
- Upload and stream videos
- Video encoding via FFmpeg
- Simple web interface

## Tech
- Backend: Node.js / Python
- Video processing: FFmpeg
- Frontend: HTML/JS
## Before running
- make a videos folder and but inside it your video
- use ffmpeg to transcript it  

## Run
1. Clone repo:
```bash
git clone https://github.com/jamalgoogle/StreamHub-HlsEncoded.git
cd StreamHub-HlsEncoded
```
```bash
npm install   # Node.js
```
```bash
npm start
